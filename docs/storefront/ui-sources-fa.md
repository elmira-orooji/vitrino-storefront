# منابع رابط صفحه محصول

الگوی گالری، انتخاب تنوع و کنترل تعداد از [E-commerce Product Detail اثر dhileepkumargm در 21st](https://21st.dev/@dhileepkumargm/components/e-commerce-product-detail) گرفته شده است. کد نمونه از اتصال 21st دریافت و برای این پروژه بازنویسی شد.

در نسخه ویترینو، داده ثابت کوله‌پشتی با محصولات فروشگاه جایگزین شده، رابط راست‌به‌چپ است و رنگ‌ها از توکن‌های موجود می‌آیند. گالری از تصویرسازی‌های محلی استفاده می‌کند؛ نماهای نزدیک، برش همان تصویر هستند و عکس واقعی کالا محسوب نمی‌شوند. انتخاب اندازه برای کفش الزامی است و تعداد سقف مشخص دارد.

تب‌های اطلاعات محصول با نقش‌های دسترس‌پذیری، کلیدهای جهت، Home و End کار می‌کنند. نوار خرید موبایل بالاتر از ناوبری پایین قرار می‌گیرد. سبد در این تکه همچنان شمارنده آزمایشی است؛ ذخیره اقلام و تنوع‌ها در مرحله سبد خرید انجام خواهد شد.

## فونت

فونت فارسی [وزیرمتن](https://github.com/rastikerdar/vazirmatn) از بسته [Fontsource](https://fontsource.org/fonts/vazirmatn) بارگذاری می‌شود. نسخه متغیر از وزن‌های میانی نیز پشتیبانی می‌کند و فایل‌ها همراه خروجی برنامه ارائه می‌شوند. درخواست فونت به Google Fonts حذف شده است.

مجوز فونت OFL-1.1 است. متن مجوز همراه نسخه منتشرشده در `public/licenses/vazirmatn-OFL.txt` نگهداری می‌شود. ابزار فعلی 21st جست‌وجوی مستقلی برای فونت ندارد؛ بنابراین فونت فارسی از منبع اصلی آن انتخاب شده است.
# منابع رابط کاربری

## Cross UI

صفحه ورود بر پایه الگوی کامپوننت‌های مستقل، متغیرهای CSS و رویکرد mobile-first معرفی‌شده در [Cross UI](https://cross-ui.ir/) ساخته شده است. چون در زمان پیاده‌سازی، مستندات عمومی و قابل اتکایی برای نصب بسته React در سایت در دسترس نبود، فرم با کامپوننت‌های محلی پروژه نوشته شد و وابستگی نامشخصی اضافه نشد.

## تصاویر محصولات

عکس‌های واقعی محصول از Unsplash استفاده شده‌اند. لینک صفحه اصلی هر عکس و نام عکاس در داده محصول نگه‌داری می‌شود و در گالری جزئیات قابل مشاهده است.
